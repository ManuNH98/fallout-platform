# 00. Product vision

## Summary

This project is a Spanish-first web platform focused on the Fallout universe.

The first core feature is a classic wiki, but the long-term goal is a broader Fallout platform with tools, guides, mods, user accounts, saved content, and Fallout 76 build planning.

## Product positioning

This is not only a wiki.

It should become a Fallout hub with:

- Wiki pages
- Game database
- Character, faction, location, quest, item, weapon, armor and creature pages
- Lore articles
- Guides
- Mod recommendations
- Fallout 76 builds
- S.P.E.C.I.A.L. planner
- Perk card database
- User accounts
- Saved builds
- Favorites
- Admin-managed content
- Possible community features in the future

## Initial language

Spanish first.

The first version should be written and managed in Spanish.

Multi-language support may be considered in the future, but it is not part of the initial scope.

## Initial editor model

At the beginning, content is created and edited only by the project owner/admin.

Community editing is not part of the initial version.

The architecture should not block future community features.

## Content principles

Content should be:

- Original
- Curated
- Structured
- Searchable
- SEO-friendly
- Connected through relationships
- Supported by references where useful
- Avoiding copied text from external wikis

## Target modules

### Phase 1 modules

- Public home
- Wiki
- Games
- Categories
- Admin panel
- Auth
- Media/storage
- Basic search

### Phase 2 modules

- Guides
- Mods
- User favorites
- User profiles
- Fallout 76 builds foundation

### Phase 3 modules

- Full S.P.E.C.I.A.L. planner
- Perk cards
- Saved builds
- Public/private builds
- Build sharing

### Future modules

- Comments
- Ratings
