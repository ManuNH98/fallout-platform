# Prompt: Review changes

Revisa los cambios actuales del repo.

## Contexto

Sigue:

- `AGENTS.md`
- `docs/`
- `.ai/skills/`

## Tarea

Haz una revisión técnica de los cambios.

## Revisa

1. Si los cambios respetan la arquitectura.
2. Si hay archivos modificados fuera de alcance.
3. Si hay duplicación de tipos o validaciones.
4. Si hay lógica de negocio en el sitio incorrecto.
5. Si hay problemas de seguridad.
6. Si hay problemas de naming o estructura.
7. Si hay problemas con Next.js, NestJS, Prisma, Supabase o Turborepo.
8. Si hay errores probables de TypeScript.
9. Si faltan tests o validaciones razonables.
10. Si la documentación debe actualizarse.

## Responde con

- Resumen general.
- Problemas bloqueantes.
- Problemas recomendados.
- Mejoras opcionales.
- Comandos de validación recomendados.
- Prompt exacto para corregir los problemas principales.

## Restricciones

- No modifiques archivos salvo que se te pida expresamente.
- Sé específico: menciona archivos y patrones concretos.
